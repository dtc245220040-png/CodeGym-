# CodeGym - Bài tập phối màu cho newsletter

Dự án gồm hai phiên bản newsletter responsive, dùng Bootstrap 5.3.3 qua CDN.

## Cách xem
- Mở `index.html` để xem phiên bản 1 (xanh ngọc).
- Mở `newsletter_version2.html` để xem phiên bản 2 (tím và cam).

## Bảng màu
### Phiên bản 1 - Xanh ngọc
- Primary: `#176B87`
- Secondary: `#64CCC5`
- Accent: `#DAFFFB`
- Text: `#183B4E`
- Background: `#F2FBFA`

### Phiên bản 2 - Tím và cam
- Primary: `#452B63`
- Secondary: `#F08A5D`
- Accent: `#F9EDC9`
- Text: `#30243D`
- Background: `#FFF9F1`

Hai bộ màu được lựa chọn cho mục đích thực hành phối màu. Bootstrap được tải từ CDN nên cần có kết nối internet để hiển thị đầy đủ kiểu dáng.
